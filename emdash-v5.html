ABOUT.SYS
Emdash is an open-source desktop environment for developers who work with multiple AI coding agents simultaneously. It provides a unified workspace where Claude, GPT, and local models run side-by-side with conflict resolution built in. Each agent operates in its own "pane" with shared context, diff merging, and a supervisor layer.
Compatible with Claude Code, Cursor, Aider, and OpenCode. MCP-aware. Local-first.
